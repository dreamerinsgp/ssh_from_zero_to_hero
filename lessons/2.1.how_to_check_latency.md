Q2: What ICMP is ?
ICMP stands for Internet Control Message Protocol. It’s a network layer protocol used for diagnostics, error reporting, and network management.

Q3: What's the role of ping ? 
Ping is a network diagnostic tool that tests connectivity between two devices. The name comes from sonar "ping" (sending a signal and waiting for an echo).

Q4: How does ping work to test latency?
1) What is Latency?
Latency (or Round-Trip Time - RTT) is the time it takes for a packet to travel from your computer to the destination and back

Q5: How to estimate latency based on ping response?
Response: 
Pinging www.a.shifen.com [180.101.49.44] with 32 bytes of data:
Reply from 180.101.49.44: bytes=32 time=10ms TTL=53
Reply from 180.101.49.44: bytes=32 time=12ms TTL=53
Reply from 180.101.49.44: bytes=32 time=8ms TTL=53
Reply from 180.101.49.44: bytes=32 time=8ms TTL=53

Ping statistics for 180.101.49.44:
    Packets: Sent = 4, Received = 4, Lost = 0 (0% loss),
Approximate round trip times in milli-seconds:
    Minimum = 8ms, Maximum = 12ms, Average = 9ms

Explanation:
The latencies are:
Packet 1: 10ms
Packet 2: 12ms
Packet 3: 8ms
Packet 4: 8ms

Minimum = min(10, 12, 8, 8) = 8ms
Maximum = max(10, 12, 8, 8) = 12ms
Average = (10 + 12 + 8 + 8) ÷ 4
        = 38 ÷ 4
        = 9.5ms
